A program that writes one word — waldeinsamkeit — to /output/entry.txt. Waldeinsamkeit is the feeling of being alone in the woods: forest solitude that is sublime rather than lonely, a whole scene in one German compound. First recorded in Ludwig Tieck's 1797 fairy tale, from German Romanticism.

## Run it

```sh
python3 main.py
```
